# 接入清单 —— 你要填的就这些

> 全程只改 **一个文件 `.env`**（从 `.env.example` 复制），加上公众号的 wechat2rss 地址。
> 每一项都是**可选**的：填了就生效，不填就自动跳过。建议按优先级从上往下填。

复制模板：
```bash
cp .env.example .env
```

---

## ① 先让它能推给你（最推荐，5 分钟）—— Telegram Bot

1. Telegram 里搜 **@BotFather** → 发 `/newbot` → 按提示起名 → 拿到一串 **token**。
2. 给你新建的 bot 随便发一句话「hi」。
3. 浏览器打开：`https://api.telegram.org/bot<你的token>/getUpdates`，
   找到 `"chat":{"id":123456789}` 里的数字，就是你的 **chat id**。
4. 填进 `.env`：
   ```
   TELEGRAM_BOT_TOKEN=刚才的token
   TELEGRAM_CHAT_ID=刚才的数字
   ```
5. 跑 `PYTHONPATH=src python -m digest run`，就能收到今日重点了（此时只有 RSS 源有内容）。

## ② AI 摘要（可选，强烈建议）—— Claude

- 到 https://console.anthropic.com/ 拿一个 API Key。
- 填：`ANTHROPIC_API_KEY=sk-ant-...`
- 不填也行：会用文章自带摘要，只是没有 AI 提炼的一句话重点。

---

## ③ 抓 Telegram 频道（你给的 4 个频道要生效，需要这个）

- 到 https://my.telegram.org → 登录 → API development tools → 拿 **api_id** 和 **api_hash**。
- 填：
  ```
  TELEGRAM_API_ID=数字
  TELEGRAM_API_HASH=一串字母数字
  ```
- 首次运行会让你用**手机号登录一次**（收验证码），之后自动记住。
- ⚠️ 建议用一个**小号**，不要用主力账号。

---

## ④ 抓 13 个微信公众号 —— 需要 wechat2rss（稍麻烦，见单独文档）

公众号没有官方接口，必须先搭 **wechat2rss** 把它们转成 RSS。
详细部署见 👉 `docs/wechat2rss-部署.md`。

搭好后，你会为每个号拿到一个 RSS 地址，把它填到 `config/sources.yaml` 里对应号的
`rss_url: ""` 引号中间。例如：
```yaml
  - id: wx_jiangelaoanquan
    name: "建哥聊安全"
    rss_url: "https://你的wechat2rss/feed/xxxx.xml"   # 填这里
```
（这一步我可以在你拿到 wechat2rss 地址后帮你**批量填好**，你只要把地址发我。）

---

## ⑤ 推到微信（可选，二选一或都要）

**企业微信机器人**（推荐，官方稳定）
- 企业微信群 → 右上 … → 添加群机器人 → 复制 **Webhook 地址**。
- 填：`WECOM_WEBHOOK=整段webhook地址`

**Server酱**（转发到个人微信）
- 到 https://sct.ftqq.com 登录 → 拿 **SendKey**。
- 填：`SERVERCHAN_KEY=你的key`

## 填完怎么验证

```bash
PYTHONPATH=src python -m digest sources    # 看 ✅ 变多了
PYTHONPATH=src python -m digest preview    # 先预览不推送
PYTHONPATH=src python -m digest run        # 正式推一次
PYTHONPATH=src python -m digest serve      # 满意后常驻，每天 9 点自动推
```

## 最小可用组合

只填 ①（Telegram Bot）就能收到 **8 个安全 RSS 源** 的每日重点。
② 让摘要更好，③ 加上 TG 频道，④ 加上公众号，⑤ 让它也发到微信。
一步步来即可，不用一次填完。
