# 服务器部署（7×24 常驻自动推送）

把整套挂到一台服务器上，常年自动每天推送，不用开着自己电脑。

## 一、买什么服务器（重要，别买错）

| 要求 | 原因 |
|------|------|
| **操作系统：Windows Server**（2019/2022） | 微信群推送靠 WeChatFerry，只能跑 Windows |
| **地域：香港 / 海外**（**不要大陆**） | 大陆服务器连不上 Telegram（被墙）；香港/海外能同时连 Telegram 和微信 |
| **规格：2 核 4G 起**，硬盘 40G+ | 跑电脑微信 + wcfhttp + Python 主程序够用 |
| 需要**桌面**（不是纯命令行） | 电脑微信要扫码登录，需要图形界面（用远程桌面 RDP 连上去操作） |

> 只要 Telegram、不要微信群？那可以买便宜的**香港 Linux VPS**（1核1G 即可），
> Docker 一键跑，省一半钱。但你要微信群，就得 Windows。

## 二、Windows 服务器上部署（一台全搞定）

远程桌面（RDP）连上服务器后：

### 1) 装 Python + 项目
- 装 Python 3.11（python.org，安装时勾选 Add to PATH）。
- 把项目压缩包传上去解压，双击 `run_local.bat`（自动建环境、装依赖、生成 .env）。

### 2) Telegram（服务器能连，直接通）
- `.env` 填 `TELEGRAM_BOT_TOKEN` + `TELEGRAM_CHAT_ID`。
- 取 chat_id：`set PYTHONPATH=src && .venv\Scripts\python -m digest tg-chats`

### 3) 微信群（WeChatFerry）
- 服务器上装指定版本电脑微信，用**小号**扫码登录，拉进目标群。
- `pip install wcfhttp` → `wcfhttp --host 127.0.0.1 --port 9999`
- 查群 `@chatroom` id（见 `WeChatFerry-Windows部署.md`），填 `.env`：
  ```
  WCF_HTTP_ENDPOINT=http://127.0.0.1:9999
  WCF_RECEIVER=xxxx@chatroom
  ```

### 4) 常驻 + 开机自启
先测试一次：
```
set PYTHONPATH=src && .venv\Scripts\python -m digest run
```
两个群都收到后，设为常驻自动推送。二选一：

**方式 A：任务计划程序（简单）**
- 打开「任务计划程序」→ 创建任务 → 触发器「登录时/开机时」→ 操作运行：
  `cmd /c "cd /d C:\path\to\项目 && set PYTHONPATH=src && .venv\Scripts\python -m digest serve"`
- 勾「不管用户是否登录都运行」，这样重启后自动拉起。

**方式 B：NSSM 注册成 Windows 服务（更稳）**
- 下载 nssm → `nssm install DailyDigest`
- Application 填 `.venv\Scripts\python.exe`，参数 `-m digest serve`，
  启动目录填项目根，环境变量加 `PYTHONPATH=src`。
- `nssm start DailyDigest`，之后开机自启、崩溃自动重启。

> 注意：wcfhttp 和电脑微信也要保持常开（同样可用任务计划/NSSM 拉起，或登录态保活）。

## 三、以后维护
- 改来源/权重：编辑 `config/sources.yaml`、`config/watchlist.yaml`，重启 serve 生效。
- 换群/换 token：改 `.env` 重启。
- 从本地迁到服务器：把 `.env` 和 `config/` 拷过去即可；若 wcfhttp 在同机，
  `WCF_HTTP_ENDPOINT` 保持 `127.0.0.1:9999`。

## 四、纯 Linux 方案（仅 Telegram，无微信群）
香港 Linux VPS 上：
```
cp .env.example .env      # 填 TELEGRAM_*
cd docker && docker compose up -d      # 或 pip install -r requirements.txt && python -m digest serve
```
微信群留到有 Windows 时再加（改 .env 的 WCF_* 即可，主程序不用动）。
