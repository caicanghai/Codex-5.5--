# 睡醒三步照做（把 Telegram 群打通）

> 前提：项目已解压，双击过一次 `run_local.bat`（已建好 .venv、生成 .env）。
> 之前的 token 报了 401（失效），第 1 步先拿一个有效的。

## 第 1 步：拿有效 token
1. 打开与 **@BotFather** 的对话，发 `/token`
2. 选 **@facaihaidafubot**
3. 复制它回你的那一整串 token（`数字:字母数字`，别漏字符别带空格）
4. 打开项目里的 `.env`，填：
   ```
   TELEGRAM_BOT_TOKEN=粘贴这里
   ```
   顺手先验证：浏览器打开 `https://api.telegram.org/bot粘贴token/getMe`，看到 `"ok":true` 就对了。

## 第 2 步：拿群 id（一条命令搞定）
在项目目录开命令行（cmd），运行：
```
set PYTHONPATH=src && .venv\Scripts\python -m digest tg-chats
```
它会：验证 token → 自动清除旧连接 → 列出你的群和 chat_id。
把群"11"那行的 `chat_id`（负数）填进 `.env`：
```
TELEGRAM_CHAT_ID=-49xxxxxxxx
```
> 若显示"还没看到会话"：去群里发一句"测试"，再重跑这条命令。

## 第 3 步：正式推 + 常驻
```
set PYTHONPATH=src && .venv\Scripts\python -m digest run      测试推一次(群里应收到)
set PYTHONPATH=src && .venv\Scripts\python -m digest serve    满意后常驻，每天9点自动推
```

到这 Telegram 就通了，能收到 13 个已就绪源的每日重点。

## 微信群（等你有空再弄，不急）
1. 电脑微信用**小号**登录，拉进目标群
2. `pip install wcfhttp && wcfhttp --port 9999`
3. 用 `docs/WeChatFerry-Windows部署.md` 里的脚本查群的 `xxxx@chatroom` id
4. `.env` 填 `WCF_HTTP_ENDPOINT=http://127.0.0.1:9999` 和 `WCF_RECEIVER=xxxx@chatroom`
5. 再 `python -m digest run`，微信群也收到
