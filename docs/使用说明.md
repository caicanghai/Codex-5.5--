# 安全资讯每日重点 — 使用说明

自动抓取 微信公众号 / Telegram 频道 / 安全资讯 RSS，每天筛选重点事件，
推送到 Telegram Bot / 企业微信机器人 / Server酱。

## 目录结构

```
config/
  sources.yaml          # 来源清单（已登记你的 13 公众号 + 4 TG 频道 + 8 RSS）
  watchlist.yaml        # 威胁关键词加权（银狐/Lumma/DcRat...）
  config.example.yaml   # 主配置（调度/打分/摘要/渠道开关）
src/digest/             # 程序代码
.env.example            # 密钥模板 —— 复制成 .env 填好即可（见《接入清单》）
requirements.txt
```

## 快速开始

```bash
# 1) 安装核心依赖（最小可跑）
pip install -r requirements.txt          # 或仅核心: pip install feedparser httpx PyYAML

# 2) 看看哪些来源已就绪、哪些待补配置
PYTHONPATH=src python -m digest sources

# 3) 预览今日重点（不推送、不写库，安全）
PYTHONPATH=src python -m digest preview

# 4) 填好 .env 后，正式跑一次（会推送）
cp .env.example .env      # 然后按《接入清单》填 token
PYTHONPATH=src python -m digest run

# 5) 常驻定时（每天按 config 的 cron 自动推送）
PYTHONPATH=src python -m digest serve
```

## Docker 一键部署（app + wechat2rss + rsshub）

```bash
cp .env.example .env          # 按《接入清单》填好密钥
cd docker && docker compose up -d
docker compose logs -f digest # 看运行日志
# 预览（不推送）：docker compose run --rm digest python -m digest preview
```

- `digest`：主程序，按 cron 每日聚合推送（状态库持久化在 `docker/data/`）。
- `wechaty`：个人微信群网关，`docker compose logs -f wechaty` 看二维码用**小号**扫码登录。
- `wechat2rss`：`http://<IP>:8001` 扫码登录小号、添加公众号，拿到 feed 回填 sources.yaml。
- `rsshub`：`http://<IP>:1200`，把 bilibili 等转 RSS（可选）。

## 命令

| 命令 | 作用 |
|------|------|
| `python -m digest sources` | 打印每个来源就绪状态（✅ 可采集 / ⏳ 待补配置） |
| `python -m digest preview` | 跑完整流程但**不推送、不写库**，把每日重点打印出来 |
| `python -m digest run` | 完整流程 + 推送 + 记录去重状态 |
| `python -m digest serve` | 启动定时调度，按 `config.yaml` 的 cron 每日推送 |

## 设计原则：缺什么跳过什么

- 没填 `ANTHROPIC_API_KEY` → 用文章原始摘要代替 AI 摘要，照常出重点。
- 没填 Telegram API → 跳过 TG 频道采集，其它源照常。
- 公众号 `rss_url` 为空 → 跳过该号（需先接 wechat2rss，见《wechat2rss-部署》）。
- 某个源抓取失败 → 只记日志跳过，不影响整体。

所以你可以**先只接 RSS + Telegram Bot 推送**跑起来，其余边跑边补。

## 数据流

```
采集 → 归一化(Event) → 去重(URL/标题+历史库) → 打分(watchlist/时效/热度)
     → LLM 摘要(Claude,可降级) → 组装 Markdown → 多渠道推送 → 记录状态
```

详见 `docs/daily-digest-方案与架构.md`。

## 合规提示

Telegram(Telethon)、微信公众号(wechat2rss) 均为非官方手段，建议用小号；
只抓标题+摘要+链接，不转载全文；社工库类仅作新闻话题追踪，不接入为查询源。
