# 本地先跑起来（服务器还没买时的临时方案）

思路：**现在在你自己电脑上跑**，先用着；等买了服务器，只把"中间人"（微信网关 wcfhttp）
搬到服务器，改一行地址即可，其它不动。

---

## 架构上早就为"本地→服务器"留好了口子

```
        [ 你的电脑：digest 主程序 ]
                 │  按 WCF_HTTP_ENDPOINT 发送
                 ▼
   [ 中间人：WeChatFerry / wcfhttp ]  ← 现在跑在本地(localhost)，以后搬到服务器
                 │
                 ▼
            微信群（小号转发）
```

- **本地阶段**：`WCF_HTTP_ENDPOINT=http://127.0.0.1:9999`
- **搬到服务器后**：只把这行改成 `http://<服务器IP>:9999`，**其余零改动**。

---

## A. Telegram 侧：任何系统，现在就能本地跑

不需要服务器，你电脑联网就行。

```bash
pip install -r requirements.txt
cp .env.example .env
# 编辑 .env，至少填这两个（拿法见 docs/接入清单.md ①）：
#   TELEGRAM_BOT_TOKEN=...
#   TELEGRAM_CHAT_ID=-100xxxxxxxxxx   # 你的 TG 群
PYTHONPATH=src python -m digest run     # 群里立刻收到今日重点
```

## B. 微信侧：分两种情况

### B1. 你本机是 Windows → 本地直接跑 WeChatFerry（推荐）
1. 本机装指定版本电脑微信，用**小号**登录，拉进你的微信群。
2. 本机跑：`pip install wcfhttp && wcfhttp --host 127.0.0.1 --port 9999`
3. `.env` 填：
   ```
   WCF_HTTP_ENDPOINT=http://127.0.0.1:9999
   WCF_RECEIVER=xxxxxxxx@chatroom     # 查法见 docs/WeChatFerry-Windows部署.md
   ```
4. `PYTHONPATH=src python -m digest run` → 微信群收到。
> 以后买了服务器：把 wcfhttp 搬到服务器上跑，`.env` 里改成 `http://<服务器IP>:9999` 即可。

### B2. 你本机是 Mac/Linux → 微信群暂时跑不了，先用 Server酱顶着
WeChatFerry 只能 Windows。在你买到 Windows 服务器之前，微信侧先用 **Server酱**
（推到你自己微信，非群，零配置、零风险）：
```
SERVERCHAN_KEY=你的key      # https://sct.ftqq.com 拿
```
等 Windows 服务器就位，再切回微信群（把 wcferry 的两个变量填上即可）。

## 一键脚本

- **Windows**：双击 `run_local.bat`
- **Mac/Linux**：`bash run_local.sh`

脚本会：建虚拟环境 → 装依赖 → 若没有 `.env` 则从模板复制并提示你去填 →
先 `preview`（不推送）给你看效果 → 你确认后可改跑 `run`。

## 想“无人值守”每天自动推

填好 `.env` 后：
```bash
PYTHONPATH=src python -m digest serve      # 常驻，按 config 里的 cron（默认每天9点）自动推
```
让它一直开着即可（本机不关机 / 以后挂服务器）。

## 切到服务器时要做的全部事情
1. 把 `wcfhttp` 挪到（Windows）服务器上跑。
2. `.env` 改一行：`WCF_HTTP_ENDPOINT=http://<服务器IP>:9999`。
3. 重跑 `python -m digest serve`。完。
